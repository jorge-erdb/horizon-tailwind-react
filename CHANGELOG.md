# Changelog

## [3.0.0] — Nova Analytics

### Whitelabel release

- Rebranded from the upstream admin template to Nova Analytics: app name,
  logos, favicon and PWA icons, footers, metadata and all demo content.
- New theme built from the Nova brand kit (`nova_analytics_id/`): indigo
  primary, spark cyan accent, amber secondary, Nova neutral ramp, and
  Space Grotesk / Inter / JetBrains Mono typography.
- New responsive marketing landing page at `/`.
- Functional email/password authentication via Supabase Auth, with
  `/admin/*` behind a protected route.
- Removed the NFT Marketplace view and the RTL layout tree.
